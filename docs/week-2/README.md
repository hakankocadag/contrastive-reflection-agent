## English

### Overview

During Week 2, the Student Agent was improved to support dynamic prompt rules generated by the Teacher Agent.

The agent was also designed to work in a stateless manner. This means that every analysis request creates a fresh system prompt and does not reuse rules or information from previous requests.

### Completed Tasks

- Added the `PromptRule` Pydantic model.
- Added unique identifiers and version numbers to prompt rules.
- Updated the Student Agent to accept structured prompt rules.
- Added dynamic Teacher Agent rule injection.
- Implemented rule version selection.
- Ensured that only the latest version of each rule is used.
- Ensured that every analysis request builds a fresh prompt.
- Added tests for stateless behavior.
- Added tests for rule version handling.

### Prompt Rule Structure

Prompt rules are represented using the following structure:

```python
PromptRule(
    rule_id="rule-001",
    rule_text="Ignore all Python built-in function calls.",
    version=2,
)
```

Each rule contains:

- `rule_id`: Unique identifier of the rule
- `rule_text`: Instruction added to the Student Agent prompt
- `version`: Version number of the rule

### Rule Version Handling

If multiple versions of the same rule are provided, only the latest version is used.

Example:

```text
rule-001 version 1
rule-001 version 2
```

The system adds only version 2 to the final prompt.

### Stateless Behavior

The Student Agent does not store prompt rules between analysis requests.

Example:

```text
First request:
- First analysis rule

Second request:
- Second analysis rule
```

The second request does not contain the rule from the first request.

This prevents previous analyses from affecting future results.

### Prompt Kuralı Yapısı

Prompt kuralları aşağıdaki yapı ile temsil edilmektedir:

```python
PromptRule(
    rule_id="rule-001",
    rule_text="Ignore all Python built-in function calls.",
    version=2,
)
```

Her kural şu alanları içerir:

- `rule_id`: Kuralın benzersiz kimliği
- `rule_text`: Öğrenci Ajan promptuna eklenecek talimat
- `version`: Kuralın sürüm numarası

### Kural Sürüm Yönetimi

Aynı kurala ait birden fazla sürüm gönderilirse yalnızca en güncel sürüm kullanılır.

Örnek:

```text
rule-001 version 1
rule-001 version 2
```

Sistem son prompta yalnızca version 2 olan kuralı ekler.

### Stateless Çalışma

Öğrenci Ajan, analiz istekleri arasında prompt kurallarını saklamaz.

Örnek:

```text
Birinci istek:
- First analysis rule

İkinci istek:
- Second analysis rule
```

İkinci isteğin promptunda birinci isteğe ait kural bulunmaz.

Bu sayede önceki analizlerin sonraki sonuçları etkilemesi engellenir.

### Güncel Akış

```text

              ↓
PromptRule Doğrulaması
              ↓
En Güncel Kural Sürümünün Seçilmesi
              ↓
Yeni System Prompt Oluşturulması
              ↓
Öğrenci Ajan Analizi
              ↓
StudentAgentOutput
```
